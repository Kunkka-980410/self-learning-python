## 逻辑回归损失函数求导详解
### 1. 损失函数定义
### 总损失函数（带L2正则化）：

```
text

J(θ) = J_CE(θ) + J_reg(θ)

其中：
J_CE(θ) = -1/m * Σ_{i=1}^m [y_i log(h_i) + (1-y_i) log(1-h_i)]
J_reg(θ) = λ/(2m) * Σ_{j=1}^n θ_j²

h_i = h_θ(x_i) = σ(z_i) = 1/(1+e^{-z_i})
z_i = θ^T x_i = Σ_{j=1}^n θ_j x_ij
```

### 2. 先求 sigmoid 函数的导数
```
text

σ(z) = 1/(1+e^{-z})

令 σ = σ(z)，则：

σ'(z) = dσ/dz 
      = e^{-z}/(1+e^{-z})²
      = [1/(1+e^{-z})] * [e^{-z}/(1+e^{-z})]
      = σ(z) * (1 - σ(z))

即：σ'(z) = σ(z)(1-σ(z))
```

### 3. 求交叉熵部分的梯度

**对于单个样本 i，先计算 ∂J_CE/∂θ_j：**
```
text

∂J_CE_i/∂θ_j = ∂/∂θ_j [-y_i log(h_i) - (1-y_i) log(1-h_i)]
```

**使用链式法则：**
```
text

∂J_CE_i/∂θ_j = [-y_i * (1/h_i) * ∂h_i/∂θ_j] + [-(1-y_i) * (1/(1-h_i)) * (-∂h_i/∂θ_j)]
             = [-y_i/h_i + (1-y_i)/(1-h_i)] * ∂h_i/∂θ_j
             = [( -y_i(1-h_i) + (1-y_i)h_i ) / (h_i(1-h_i))] * ∂h_i/∂θ_j
             = [(-y_i + y_i h_i + h_i - y_i h_i) / (h_i(1-h_i))] * ∂h_i/∂θ_j
             = [(h_i - y_i) / (h_i(1-h_i))] * ∂h_i/∂θ_j
```

**现在求 ∂h_i/∂θ_j：**
```
text

h_i = σ(z_i)
z_i = Σ_{k=1}^n θ_k x_ik

∂h_i/∂θ_j = ∂σ(z_i)/∂θ_j 
          = σ'(z_i) * ∂z_i/∂θ_j
          = h_i(1-h_i) * x_ij  # 因为 ∂z_i/∂θ_j = x_ij
```

**代回：**

```
text

∂J_CE_i/∂θ_j = [(h_i - y_i) / (h_i(1-h_i))] * [h_i(1-h_i) * x_ij]
             = (h_i - y_i) * x_ij
```
**太棒了！交叉熵损失对 sigmoid 的梯度化简后非常简洁。**

### 4. 对所有样本求和
```
text

∂J_CE/∂θ_j = 1/m * Σ_{i=1}^m ∂J_CE_i/∂θ_j
           = 1/m * Σ_{i=1}^m (h_i - y_i) * x_ij
```
**写成向量形式：**
```
text

∇_θ J_CE = 1/m * X^T (h - y)
```
**其中：**

**`X` 是 `m×n` 的设计矩阵**

**`h = [h_1, h_2, ..., h_m]^T` 是预测向量**

**`y = [y_1, y_2, ..., y_m]^T` 是真实标签向量**

### 5. 求正则化部分的梯度
```
text

J_reg(θ) = λ/(2m) * Σ_{j=1}^n θ_j²
```

**向量形式：**
```
text

∇_θ J_reg = (λ/m) * θ
∂J_reg/∂θ_j = λ/(2m) * 2θ_j = (λ/m) * θ_j
```

**注意：通常不对偏置项 θ₀ 进行正则化，所以实际中：**
```
text

∂J_reg/∂θ_j = 
⎧ 0,                   if j = 0 (偏置项)
⎨
⎩ (λ/m) * θ_j,        if j > 0
```

### 6. 总梯度
```
text

∇_θ J(θ) = ∇_θ J_CE + ∇_θ J_reg
         = 1/m * X^T (h - y) + (λ/m) * θ
```

**更精确地（考虑偏置项不正则化）：**
```
text

∂J/∂θ_j = 
⎧ 1/m * Σ_{i=1}^m (h_i - y_i),        if j = 0
⎨
⎩ 1/m * Σ_{i=1}^m (h_i - y_i) x_ij + (λ/m) θ_j,  if j > 0
```

### 7. 梯度下降更新规则
```
text

θ_j := θ_j - α * ∂J/∂θ_j
```
**其中 α 是学习率**

---
### 8. 求导过程总结表
|步骤|	公式|	说明
|:---|:---|:---
|1. 定义损失	|J(θ) = -1/m Σ[y log(h) + (1-y)log(1-h)] + λ/(2m) Σθ²	|交叉熵 + L2正则
|2. sigmoid导数|	σ'(z) = σ(z)(1-σ(z))	|关键性质
|3. 单个样本梯度|	∂J_i/∂θ_j = (h_i - y_i) x_ij	|经过化简
|4. 总交叉熵梯度|	∇J_CE = 1/m X^T(h-y)	|向量形式
|5. 正则化梯度|	∇J_reg = (λ/m) θ	|L2正则的梯度
|6. 总梯度	∇J = 1/m X^T(h-y) + (λ/m) θ|	最终结果

### 10. 手算示例
**假设有2个样本，1个特征：**
```
text

数据：
x₁ = 2, y₁ = 1
x₂ = 3, y₂ = 0

参数：
θ = 0.5
λ = 0.1, m = 2, α = 0.1

计算：
h₁ = σ(0.5*2) = σ(1.0) = 1/(1+e^{-1}) ≈ 0.731
h₂ = σ(0.5*3) = σ(1.5) = 1/(1+e^{-1.5}) ≈ 0.818

梯度：
∂J/∂θ = 1/2 * [(0.731-1)*2 + (0.818-0)*3] + (0.1/2)*0.5
      = 1/2 * [(-0.269)*2 + 0.818*3] + 0.025
      = 1/2 * [-0.538 + 2.454] + 0.025
      = 1/2 * 1.916 + 0.025
      = 0.958 + 0.025 = 0.983

更新：
θ_new = 0.5 - 0.1 * 0.983 = 0.5 - 0.0983 = 0.4017
```
**这就是完整的求导过程和梯度下降更新。**
