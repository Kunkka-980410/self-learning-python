## 📉 梯度下降法求解线性回归参数

```text
1️⃣ 初始化参数
设定初始值： a = 0.0 # 初始斜率
b = 0.0 # 初始截距
η = 0.01 # 学习率（learning rate）
```
```text
2️⃣ 计算预测值
对每个样本点 X_i，根据当前参数计算预测值： Y_hat_i = a * X_i + b
```
```python
Y_pred = a * X + b
```

```text
3️⃣ 计算损失函数（均方误差）
衡量预测值与真实值之间的差距： L(a, b) = (1/n) * Σ(Y_i - Y_hat_i)^2
Python代码： loss = np.mean((Y - Y_pred) ** 2)
```

```text
4️⃣ 计算梯度（对参数求偏导）
对 a 的梯度： ∂L/∂a = -(2/n) * Σ X_i * (Y_i - Y_hat_i)
对 b 的梯度： ∂L/∂b = -(2/n) * Σ (Y_i - Y_hat_i)
Python代码： grad_a = -2 * np.mean(X * (Y - Y_pred))
grad_b = -2 * np.mean(Y - Y_pred)
```

```text
5️⃣ 更新参数
根据梯度和学习率更新参数： a = a - η * grad_a
b = b - η * grad_b
```

```text
6️⃣ 重复迭代直到收敛 重复步骤 2～5，直到达到最大迭代次数或损失函数变化很小：
Python代码：
```
```python
for epoch in range(max_iter):
    Y_pred = a * X + b
    grad_a = -2 * np.mean(X * (Y - Y_pred))
    grad_b = -2 * np.mean(Y - Y_pred)
    a -= η * grad_a
    b -= η * grad_b
```

---
✅ 什么是“收敛”？
收敛的意思是：参数更新越来越小，损失函数越来越稳定，模型已经接近最优解。

🔍 常见的收敛判断方式
你可以用以下几种方式判断是否收敛：

1️⃣ 损失函数变化很小（推荐）
每次迭代都计算损失函数，如果连续几次变化都很小，就认为收敛了：

```python
if abs(prev_loss - current_loss) < ε:
    break
```
其中 ε 是一个很小的阈值，比如 1e-6。

2️⃣ 梯度接近零
如果梯度本身已经很小，说明参数不再需要更新：

```python
if abs(grad_a) < ε and abs(grad_b) < ε:
    break
```
3️⃣ 达到最大迭代次数（兜底）
设置一个最大迭代次数，比如 1000 次，防止死循环：

```python
for epoch in range(max_iter):
```
    ...
🧠 实战建议
通常你会结合使用：

损失函数变化阈值（主判断）

最大迭代次数（兜底）

梯度大小（可选）

这样既能保证收敛，又能防止卡死。

✅ 示例代码片段
```python
max_iter = 10000
ε = 1e-6
prev_loss = float('inf')

for epoch in range(max_iter):
    Y_pred = a * X + b
    loss = np.mean((Y - Y_pred) ** 2)
    
    if abs(prev_loss - loss) < ε:
        print(f"收敛于第 {epoch} 次迭代，损失变化小于阈值")
        break
    
    grad_a = -2 * np.mean(X * (Y - Y_pred))
    grad_b = -2 * np.mean(Y - Y_pred)
    a -= η * grad_a
    b -= η * grad_b
    prev_loss = loss
```
